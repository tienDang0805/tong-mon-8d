# Workspace Rules — Tông Môn 8D: Tu Tiên Chi Lộ

1. **Zero Comments in Code**: Never write comments (`//`, `/* */`, `#`, `<!-- -->`) in any source code file or code block. Self-documenting identifiers and strict TypeScript typing are mandatory.
2. **Canonical Fidelity**: All 18 ordered cultivation entries (`Phàm Nhân` + 17 major realms) and 10 legendary NPCs must strictly match `docs/DECISIONS.md`, `docs/GAME_LORE.md`, `docs/CHARACTER_VISUAL_BIBLE.md`, and `packages/game-data/` (`src/catalogs/realms.ts`, `src/catalogs/destinies.ts`, `src/index.ts`; historical provenance in `docs/archive/legacy/MASTER_PROMPT.md`). Never invent a definitive realm for `dam_lon_tien_tu` (`UNKNOWN`).
3. **Server Authority**: Browser clients submit intents only (`move`, `interactPortal`, `attack`, `skill`, `buyItem`, `cookRecipe`, `submitQuest`, `claimMeditation`, `breakthrough`, `partyAction`). The Colyseus server validates range, cooldowns, collisions, inventory, currency, and idempotency keys inside transactional persistence.
4. **Playfield First**: Phaser 4 WebGL/Canvas owns the playfield. DOM HUD must be compact, thematic, and never obscure the center playfield during normal movement.
5. **Cohesive Pixel Art & Tiled Maps**: Use nearest-neighbor (`pixelArt: true`) rendering, `32x32` world tiles, profile-driven character/creature sprite geometry compiled from `assets/corekit/v01b/profiles/animation.json` (`full_80x96_20row` `480x1920`, `full_80x96_20row_8walk` `640x1920`, `locomotion_80x96_8row` `480x768`, `stationary_npc_80x96_4f` `320x96` at foot anchor `(0.5, 0.9167)` / `(40, 88)`, alongside preserved `legacy_48x64_16row` `288x1024` at `(0.5, 0.90)` / `(24, 58)`), and genuine Tiled JSON (`.tmj`) layered maps (`96x72` `tan_thu_thon` ↔ `44x32` `thanh_truc_lam`).
6. **Genuine Native Generative Art, Core Kit Resolution & Human Creative Approval**: All new final visual artwork must originate from the Argon host's built-in `image-generator` subagent with exact active master references resolved from `assets/corekit/v01b/catalog.json` attached, or from owner-approved AI-generated source artwork. Never substitute Python/Pillow/SVG/Canvas procedural or geometric drawing (`ImageDraw`, `codeart2d`, disabled `build_assets.py`) or affine-warped single-frame motion for production artwork, and never conflate automated `TECHNICALLY_VERIFIED` checks with `HUMAN_APPROVED` creative sign-off.

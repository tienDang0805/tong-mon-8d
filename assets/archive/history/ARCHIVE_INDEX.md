# Historical & Rejected Art Archive (`assets/archive/history/`)

> [!WARNING]
> Every file under `assets/archive/history/**` has `role: "archive_only"` and is **strictly forbidden** as an active visual master or runtime asset. `npm run verify:assets` fails if any active reference or runtime asset points into this directory.

- **Archive Manifest**: [`archive_manifest.json`](./archive_manifest.json)
- **Archived Categories**:
  - `concepts/`: 11 Phase 0 concept exploration sheets (including superseded `candidate_a_classic_xianxia.jpg`).
  - `legacy_v1/`: 9 unique historical `48x64` v1 prototype character sheets.
  - `pre_correction_npcs/`: 4 rejected pre-correction `phi_de` and `rmt_de` files preserved solely as negative-validation evidence.
  - `comparison_boards/`: Owner Phì Đế / RMT Đế comparison board containing `OLD (REJECTED)` panes (never use as an unrestricted master).
